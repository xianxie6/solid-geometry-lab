# 立体几何实验室

[在线体验（无需登录）](https://cone-unfolding-lab-xian.lively-bud-4907.chatgpt.site/)

同一网站内切换 10 道高中立体几何题。桌面用侧边目录，手机用下拉选择，也可点击上一题、下一题。各题提供题干、动态模型、面积结果与推导；切题后停止当前动画并载入下一题的默认状态。

## 题目与交互

1. 圆锥展开：调整半径、高度与展开进度；可切换 Blender 视频。
2. 正四棱锥展开：四个侧面绕底边打开，斜高与面积保持不变。
3. 圆台展开：侧面等距展开成扇环；计算结果另计两个底面。
4. 正方体切角：调整切割位置，移开小角，观察增减面积。
5. 正方体动态截面：固定 x+y+z=t 方向，平移切面，显示真实截形及面积曲线。
6. 球的截面：调整切面距球心距离，同时观察圆形截面、直角三角形和面积曲线。
7. 圆锥平行截面：调整切面高度，比较截面积与底面积比例。
8. 绕斜边旋转：直角三角形扫出共底双圆锥。
9. 圆柱与半球组合：拆开观察隐藏的接触圆面。
10. 圆柱面积最值：固定体积，改变半径，联动高度与面积曲线。

圆锥 Blender 视频使用固定 r=3、h=4，时长 10 秒；交互模型可调整参数。其余九题使用浏览器实时几何投影。图形网格用于显示，结果使用解析公式。图形与平面截面示意独立缩放，所有单位均在页面说明。

## 本地运行与验证

```sh
npm install
npm run dev
node scripts/verify-solids.mjs
npx tsc --noEmit
npm run build
```

几何验证覆盖 189 个模型状态、展开面积守恒、切角表面积、121 个正方体截面、球与圆锥截面、双圆锥、组合体与固定体积最值。多边形结果采用精确误差限，曲面网格采用离散化误差限。

原圆锥 `lib/cone.ts` 使用可展圆锥族等距展开，母线长度、边界弧长和曲面面积保持不变。既有验证覆盖 4 组尺寸、7 个展开位置、4096 段数值采样。其 WebMCP `configure_cone` 在圆锥题挂载期间使用同一 React 状态及参数校验。
